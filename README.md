# 🏠 Dormix – Smart Hostel & PG Management Platform

Dormix is a modern full-stack Hostel & PG Management System built to simplify hostel administration and improve the student experience.

---

# ✨ Features

## 👨‍🎓 Student Module

- Secure Login
- Responsive Dashboard
- Room Information
- Fee Details
- Complaints
- Notices
- Profile Management

---

## 👨‍💼 Admin Module

- Responsive Dashboard
- Student Management
- Room Management
- Fee Management
- Complaint Management
- Notice Management
- Warden Management
- System Settings
